# Ассемблер и интерпретатор УВМ (вариант 17)

Практическая работа № 3 по дисциплине «Конфигурационное управление».

## Общее описание

Учебная виртуальная машина (УВМ) с одним регистром-аккумулятором и общей
памятью для команд и данных. Проект состоит из ассемблера и интерпретатора
(CLI-приложения на Python 3.9+).

Текущее состояние — **этап 1**: ассемблер разбирает программу на языке YAML
и переводит её во внутреннее представление (список команд с полями A и B).
В режиме тестирования внутреннее представление выводится на экран.

Внешняя зависимость одна — [PyYAML](https://pypi.org/project/PyYAML/) для
разбора YAML (`pip install -r requirements.txt`). Остальное — стандартная
библиотека: `argparse`, `dataclasses`, `unittest`.

## Структура репозитория

```
src/
  assembler.py   точка входа ассемблера: параметры, режим тестирования
  isa.py         спецификация команд УВМ: коды операций, размеры, поля
  source.py      разбор YAML-программы во внутреннее представление
  errors.py      общее исключение UvmError
programs/        программы на языке ассемблера
scripts/         скрипты ОС для демонстрации работы
tests/           модульные тесты (unittest)
run.sh           запуск ассемблера и тестов
```

## Спецификация УВМ

Команда состоит из поля A (код операции, биты 0—6) и поля B (операнд,
начинается с бита 7). Команды хранятся в памяти и в файле младшим байтом
вперёд.

| Команда | Мнемоника    | A   | Поле B           | Размер | Действие                          |
| ------- | ------------ | --- | ---------------- | ------ | --------------------------------- |
| Загрузка константы | `load_const` | 81  | биты 7—22, константа | 3 байта | `acc = B`                |
| Чтение из памяти   | `read`       | 49  | биты 7—17, смещение  | 3 байта | `acc = memory[acc + B]`  |
| Запись в память    | `write`      | 127 | биты 7—36, адрес     | 5 байт  | `memory[B] = acc`        |
| Операция `==`      | `eq`         | 40  | биты 7—36, адрес     | 5 байт  | `acc = (acc == memory[B])` |

Тесты из спецификации:

| Команда      | Поля           | Байты                          |
| ------------ | -------------- | ------------------------------ |
| `load_const` | A=81, B=50     | `0x51, 0x19, 0x00`             |
| `read`       | A=49, B=120    | `0x31, 0x3C, 0x00`             |
| `write`      | A=127, B=351   | `0xFF, 0xAF, 0x00, 0x00, 0x00` |
| `eq`         | A=40, B=185    | `0xA8, 0x5C, 0x00, 0x00, 0x00` |

## Язык ассемблера

Программа — YAML-список команд. Каждая команда — словарь из одного ключа:
мнемоника, значение — целочисленный операнд (поле B). Операнд можно записать
в десятичном или шестнадцатеричном виде (`0x1F`).

```yaml
- load_const: 50     # acc = 50
- read: 120          # acc = memory[acc + 120]
- write: 351         # memory[351] = acc
- eq: 185            # acc = (acc == memory[185])
```

Допустимые значения операнда: `load_const` — 0..65535, `read` — 0..2047,
`write` и `eq` — 0..1073741823 (по числу бит поля B). Метки и переходы в
языке отсутствуют: программа выполняется линейно, сверху вниз.

## Настройки ассемблера

- `-i`, `--input PATH` — исходный файл с текстом программы (обязательный);
- `-o`, `--output PATH` — двоичный файл-результат (обязательный; запись
  файла появится на этапе 2);
- `-t`, `--test` — режим тестирования: вывести внутреннее представление
  программы в формате полей и значений;
- `-h`, `--help` — справка. Сокращённые имена параметров не принимаются.

Ошибки в параметрах — код завершения 2. Ошибки в программе (неизвестная
команда, операнд вне диапазона, неверный YAML) — сообщение
`assembler: error: <причина>` в stderr и код завершения 1.

## Сборка и запуск

Сборка не требуется, нужен Python 3.9+ и PyYAML.

```
pip install -r requirements.txt
./run.sh asm -i programs/spec.yaml -o out/spec.bin --test
./run.sh test                      # запуск тестов
```

Без `run.sh`:

```
PYTHONPATH=src python3 src/assembler.py -i programs/spec.yaml -o out/spec.bin -t
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Скрипты ОС (`scripts/`):

- `test_spec.sh` — трансляция `programs/spec.yaml` (тесты спецификации).

## Примеры использования

```
$ ./run.sh asm -i programs/spec.yaml -o out/spec.bin --test
A=81, B=50
A=49, B=120
A=127, B=351
A=40, B=185
```

Ошибка в программе:

```
$ ./run.sh asm -i bad.yaml -o out/bad.bin
assembler: error: bad.yaml: command #2: unknown command 'jump'
```
